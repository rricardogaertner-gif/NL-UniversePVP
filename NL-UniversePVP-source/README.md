# NL-UniversePVP (prototype v1.0.0)

Minecraft Paper PvP prototype met vijf classes en vijf 100x100 arena-generatoren.

## Build
Upload de inhoud van deze map naar de hoofdmap van GitHub-repository `NL-UniversePVP` (inclusief `.github`). Start de workflow in **Actions** en download het JAR-artifact.

## Commando's
- `/nlpvp menu` (alias `/pvpclass menu`)
- `/nlpvp save warrior|archer|tank|assassin|mage` (admin; bewaart huidige inventory/armor)
- `/nlpvp sethub` (admin)
- `/nlpvp status`
- `/nlpvp leave`

## Belangrijk
Dit is een **ontwikkelprototype**, niet getest op jouw Paper-versie. De koppeling met het HUB-portaal is nog niet geïmplementeerd. Test op een aparte testserver en maak eerst backups. Tijdelijke werelden worden aangemaakt en verwijderd; veiligheid en inventarisintegratie met Multiverse-Inventories moeten nog worden getest.
